# سَكِينَة — مشروع أندرويد أولي

مشروع Android Studio بلغة Kotlin لتطبيق سَكِينَة، وفيه:
- إضافة أصحاب مع صورة اختيارية تُحفظ داخل مساحة التطبيق.
- أدعية عامة متنوعة، ودعاء مخصص لكل صاحب.
- تذكيرات محلية يومية (مرة أو مرتين أو ثلاث مرات) مع إشعارات أندرويد.
- شاشة أذكار مع عدّاد بسيط.
- شاشة جلب مواقيت الصلاة لمدينة يكتبها المستخدم عبر AlAdhan API.
- تخزين الأسماء والإعدادات محليًا على الجهاز.

## طريقة فتح المشروع
1. فك ضغط الملف `SakinahAndroid.zip`.
2. افتح Android Studio ثم اختر **Open** وحدد مجلد `SakinahAndroid`.
3. انتظر Gradle Sync، وثبّت Android SDK Platform 35 إذا طُلب.
4. شغّل التطبيق على جهاز أندرويد أو محاكي.

## ملاحظات مهمة
- هذا مشروع مصدر قابل للفتح والبناء في Android Studio، وليس ملف APK مبنيًا.
- لم يُختبر البناء على جهاز حقيقي في بيئة المحادثة.
- أندرويد قد يؤخر بعض المنبهات بسبب وضع توفير البطارية أو صلاحيات المنبهات الدقيقة. اسمح بالإشعارات، واسمح بالتنبيهات الدقيقة من إعدادات النظام إن ظهرت.
- الشاشة الحالية تجلب مواقيت الصلاة عند الطلب؛ لا يوجد تشغيل أذان صوتي تلقائي في هذه النسخة.
- شاشة القرآن الكريم الكامل، الصوتيات، القبلة، والودجت ليست مضافة بعد. يلزم إضافة مصدر مصحف موثوق وملفات صوتية مرخّصة قبل نشر التطبيق.
- مواقيت الصلاة تعتمد على اتصال الإنترنت ومدينة المستخدم وطريقة الحساب.
- البيانات والصور مخزنة محليًا؛ حذف التطبيق قد يحذف هذه البيانات.
- قبل النشر العام، يلزم اختبار الإشعارات على إصدارات أندرويد مختلفة، تحسين معالجة إعادة تشغيل الجهاز، وإضافة صفحة الخصوصية ومراجعة سياسات Google Play.


## بناء APK من الهاتف باستخدام GitHub Actions
هذا المشروع يتضمن ملف workflow في `.github/workflows/build-apk.yml` لبناء نسخة Debug ورفع ملف APK كـ Artifact:
1. فك الضغط عن ZIP على الهاتف.
2. أنشئ مستودعًا جديدًا على GitHub من المتصفح.
3. ارفع محتويات مجلد `SakinahAndroid` كاملة إلى المستودع، مع تضمين مجلد `.github` المخفي وملف workflow.
4. افتح تبويب **Actions** في المستودع، ثم شغّل **Build Sakinah APK** إن لم يبدأ البناء تلقائيًا.
5. عند نجاح المهمة، افتح تشغيل الـ workflow ونزّل Artifact باسم `Sakinah-debug-apk`، ثم فك ضغطه لتحصل على `app-debug.apk`.
6. افتح APK على هاتف أندرويد واسمح بالتثبيت من هذا المصدر عند الطلب.

مهم: البناء السحابي يحتاج حساب GitHub واتصال إنترنت. هذه نسخة Debug للتجربة وليست إصدار متجر موقّعًا. إذا فشل البناء، افتح سجل الخطأ وأرسله للمساعدة في إصلاحه. يجب اختبار ميزات الخلفية على الهاتف الفعلي؛ لا يمكن ضمان التنبيهات الدقيقة بسبب إعدادات النظام وتوفير البطارية.
